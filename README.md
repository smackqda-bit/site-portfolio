# SMACKQ — Digital, Reimagined.

Авторский сайт независимой digital-студии: крупная типографика, хромированная интерактивная скульптура, оригинальные концепты и WebGL-эксперимент с частицами.

## Запуск

Требуется Node.js 22.20+ и npm.

```powershell
npm ci
npm run dev
```

Адрес: http://127.0.0.1:3000

Production:

```powershell
npm run build
npm start
```

## Проверки

```powershell
npm run typecheck
npm run lint
npm test
npm run build
# В отдельном терминале, когда сервер уже запущен:
npm run test:smoke
```

Серверные тесты используют подменённые HTTP-ответы. Реальные письма при тестировании не отправляются.

## Что реализовано

- Next.js App Router + React + TypeScript. Версии зафиксированы в package.json и package-lock.json.
- Three.js импортируется отдельно от основного интерфейса; GSAP загружается для scroll-анимаций. R3F, Drei, Motion и Lenis не добавлены: в этом проекте их задачи решаются меньшим числом зависимостей.
- Хромированная скульптура с процедурным окружением отражений, вращением, GPU-деформацией, реакцией на курсор и изменением камеры при прокрутке.
- Авторский wordmark, полноэкранное модальное меню, cinematic intro, единая палитра, grain, magnetic buttons, дополнительный курсор, scroll-driven проявление слов.
- About, три отдельных концептуальных кейса с галереями, раскрывающиеся услуги, доступная интерактивная схема процесса. Обложки используют shared-element переход React ViewTransition с обычной навигацией в неподдерживающих браузерах.
- WebGL-частицы оригинального wordmark SMACKQ с режимами Letterform / Orbit, отталкиванием и импульсом. Эффект загружается при приближении к секции; отдельная кнопка позволяет активировать его с клавиатуры.
- Серверная форма, SEO, отдельные Open Graph PNG для главной и кейсов, sitemap, robots, error и 404.
- Адаптивные стили, prefers-reduced-motion, ручная пауза, ограничение DPR, упрощение геометрии на мобильных/малоядерных устройствах.
- Сцены не рендерятся вне viewport или в скрытой вкладке; GPU-анимация останавливается при reduced motion. Геометрия, материалы, окружение, observers, события и RAF очищаются при размонтировании.
- При недоступном WebGL остаётся декоративный CSS-fallback. Основной контент и ссылки не зависят от сцены.

Все проекты явно помечены **Concept Project**. Названия, иллюстрации и описания — самостоятельные демонстрационные исследования, без вымышленных клиентов, наград или коммерческих результатов.

## Настройка формы

Скопируйте `.env.example` в `.env.local` и заполните реальные значения:

1. `NEXT_PUBLIC_SITE_URL` — канонический origin, например `https://your-domain.com`, без завершающего слеша.
2. `NEXT_PUBLIC_CONTACT_EMAIL` — публичный адрес студии; пока не задан, фиктивный email не выводится.
3. `RESEND_API_KEY`, `CONTACT_FROM_EMAIL`, `CONTACT_TO_EMAIL` — ключ Resend, отправитель с подтверждённого домена и реальный адрес получателя.
4. Для production: `NEXT_PUBLIC_TURNSTILE_SITE_KEY` и `TURNSTILE_SECRET_KEY`. В панели Cloudflare разрешите hostname сайта. Проверяется hostname и action `contact`.
5. Для production: `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` для общего атомарного лимита 3 обращения за 15 минут на email.
6. Опционально `CONTACT_TRUSTED_IP_HEADER` — заголовок IP, который доверенный reverse proxy всегда перезаписывает. Тогда действует и лимит по IP. Не доверяйте произвольному пользовательскому X-Forwarded-For.

После изменения публичных переменных пересоберите приложение. Почтовые секреты хранятся только на сервере.

Обработчик `POST /api/contact` проверяет origin, Content-Type, размер потока до 16 KiB, поля, honeypot, время заполнения, Turnstile и лимиты. Redis обязателен в production; локально доступен лимитер в памяти. При ошибке защиты обработчик отказывает в отправке. Письмо отправляется plain text, адрес посетителя используется только как Reply-To.

Успех возвращается только после подтверждения приёма письма API Resend. Это **приём провайдером**, а не подтверждение доставки в почтовый ящик. При отсутствии конфигурации форма показывает недоступность, а API возвращает 503. Проверьте доставку в свой настоящий ящик после настройки.

Прямые API-интеграции сверены с [Resend](https://resend.com/docs/api-reference/emails/send-email), [Cloudflare Turnstile](https://developers.cloudflare.com/turnstile/get-started/server-side-validation/) и [Upstash REST](https://upstash.com/docs/redis/features/restapi).

## Развёртывание

Подходит Node.js-хостинг с поддержкой Next.js Route Handlers, например управляемый Next.js-хостинг или собственный сервер. Статический export не подходит для контактного API. Используйте HTTPS и задайте переменные окружения до сборки. Публикация на внешнем хостинге в этой задаче не выполнялась.

Geist размещён локально через next/font/local: нет внешнего запроса Google Fonts. Используется неизменённый файл шрифта и SIL Open Font License в src/fonts/OFL.txt. Предусмотрены font-display: swap, preload и метрически настроенный fallback.

## Проверено и ограничения

- TypeScript и ESLint: без ошибок на текущем этапе.
- 26 тестов: 20 серверных и 6 проверок планирования/сглаживания анимаций — пройдены.
- Production build: итоговая версия успешно собрана 12 октября 2026.
- HTTP smoke: пройдено 19 проверок — главная, три кейса, privacy, robots, sitemap, 6 SVG-обложек, 4 Open Graph PNG, 404 и запрет чужого origin.
- Визуальная desktop/mobile проверка и реальный WebGL-рендер **не подтверждены**: встроенный браузер недоступен; headless Chrome завершился с ошибкой GPU-процесса до получения скриншота. Код не отключает защиту браузера для обхода этой ошибки.
- Реальные Turnstile, Redis и доставка почты требуют ключей владельца; тесты интеграций выполнены с подменёнными ответами.
- Lighthouse/Core Web Vitals на реальном устройстве не измерялись. Чек-лист ручной приёмки — в BROWSER-QA.md. Десять исправлений и границы аудита — в AUDIT.md.
